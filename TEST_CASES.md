# Тест-кейсы

| ID | Функция | Шаги | Ожидаемый результат |
|----|---------|------|---------------------|
| T-01 | Запуск и просмотр | Запустить `python3 main.py`, выбрать пункт 1 | Выводится не менее 5 записей оборудования |
| T-02 | Неверный пункт меню | Запустить программу, ввести `9`, затем пустую строку | Сообщение о неверном пункте, программа не завершается аварийно |
| T-03 | Выход | Запустить программу, ввести `0` | Выводится «До свидания!», программа завершается |
| T-04 | Добавление оборудования | Выбрать пункт 2, ввести уже существующий номер INV-001 и корректные остальные данные | Запись не создаётся, выводится ошибка «Запись с номером INV-001 уже существует.» |
| T-05 | Добавление оборудования | Выбрать пункт 2, оставить одно из полей пустым | Запись не создаётся, выводится сообщение, что поле не может быть пустым |
| T-06 | Добавление оборудования | Выбрать пункт 2, указать неверный тип (например, frf) | Выводится ошибка с допустимыми типами, программа возвращается в меню |
| T-07 | Добавление и просмотр | Добавить корректную запись INV-100, затем выбрать пункт 1 | Запись INV-100 есть в списке |
| T-08 | Поиск по номеру | Пункт 3, режим 1, номер INV-003 | Показана карточка записи |
| T-09 | Поиск по номеру | Пункт 3, режим 1, номер INV-999 | Сообщение «Не найдено.» |
| T-10 | Поиск по номеру | Пункт 3, режим 1, пустой ввод | Сообщение «Не найдено.», программа не завершается аварийно |
| T-11 | Повторный поиск | Дважды найти номер INV-002 | Оба раза показан одинаковый результат |
| T-12 | Поиск по кабинету | Пункт 3, режим 2, кабинет 101 | Показаны INV-001 и INV-002 |
| T-13 | Изменение состояния | Пункт 4, номер INV-001, состояние «требует ремонта» | Сообщение «Изменено», состояние записи изменилось |
| T-14 | Изменение состояния | Пункт 4, номер INV-001, состояние «сломано» | Сообщение об ошибке, запись не меняется |
| T-15 | Изменение записи | Пункт 4, номер INV-999 | Сообщение «Не найдено.» |
| T-16 | Удаление | Пункт 5, номер INV-006, ответ «нет» | «Удаление отменено.», запись осталась |
| T-17 | Удаление | Пункт 5, номер INV-006, ответ «да» | «Удалено», повторный поиск даёт «Не найдено.» |
| T-18 | Первый запуск | Запустить программу без файла data/inventory.json | Программа запускается, список пуст |
| T-19 | Сохранение | Добавить запись, выйти, запустить снова | Запись на месте |
| T-20 | Пустой файл | Оставить data/inventory.json пустым и запустить программу | Запуск без сбоя, список пуст |
| T-21 | Испорченный JSON | Записать в data/inventory.json неверный текст и запустить программу | Предупреждение, файл сохранён как inventory.json.broken, программа продолжает с пустым списком |
| T-22 | Изменение и перезапуск | Изменить состояние записи, выйти, запустить снова | Изменение сохранилось |
| T-23 | Удаление и перезапуск | Удалить запись, выйти, запустить снова | Записи в списке нет |
