# Финальная сводка

## Требования заказчика
В колледже терялась информация о компьютерном оборудовании. Нужна программа, которая позволяет просматривать, добавлять, изменять, удалять и искать инвентарные записи и сохраняет данные между запусками.

## Реализованные функции
| Функция | Реализация |
|---|---|
| Просмотр | пункт меню 1 |
| Добавление с проверкой данных | пункт меню 2: пустые поля, тип и состояние из списков, уникальный номер |
| Поиск | пункт меню 3: по номеру, по кабинету, по состоянию |
| Изменение | пункт меню 4: состояние и кабинет |
| Удаление | пункт меню 5, с подтверждением |
| Сохранение | `data/inventory.json`, загрузка при старте, сохранение после изменений |
| Устойчивость к ошибкам | отсутствующий, пустой и повреждённый файл обрабатываются без потери данных |
| Тесты | 43 автотеста |

## Полный пользовательский сценарий для демонстрации
Добавить запись, найти её по номеру, изменить состояние, выйти из программы, запустить заново и убедиться, что изменение сохранилось, затем удалить запись с подтверждением.
