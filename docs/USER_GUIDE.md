# Инструкция пользователя

## Для кого
Лаборанты и заведующие кабинетами колледжа, которым нужно вести учёт компьютерного оборудования.

## Установка и запуск
1. Установите Python 3.11 или новее.
2. Откройте терминал в папке проекта и создайте окружение: `python3 -m venv .venv` (в Windows `python -m venv .venv`).
3. Активируйте его: `source .venv/bin/activate` (в Windows `.venv\Scripts\Activate.ps1`).
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите программу: `python3 main.py` (в Windows `python main.py`).

## Работа с меню
Введите номер пункта и нажмите Enter.

| Пункт | Что делает |
|---|---|
| 1 | Показывает все записи об оборудовании |
| 2 | Добавляет запись: спрашивает номер, тип, наименование, кабинет и состояние |
| 3 | Ищет записи: по инвентарному номеру, по кабинету или по состоянию |
| 4 | Меняет состояние или кабинет записи |
| 5 | Удаляет запись после подтверждения (ответ «да») |
| 0 | Выход |

Тип выбирается из списка: ПК, монитор, принтер, проектор, другое. Состояние: исправно, требует ремонта, списано.

## Типичные ситуации
- **Номер уже существует.** Программа выводит ошибку и запись не добавляет. Укажите другой номер.
- **Пустое поле.** Все пять полей обязательны.
- **«Не найдено.»** Записи с таким номером, кабинетом или состоянием нет. Проверьте ввод.
- **Удаление.** Перед удалением показывается карточка записи; любой ответ, кроме «да», отменяет удаление.

## Где хранятся данные
В файле `data/inventory.json`. Он создаётся и обновляется автоматически. Если файл повреждён, программа переименует его в `data/inventory.json.broken`, выведет предупреждение и начнёт с пустого списка. Исходные данные при этом сохраняются в копии, и их можно восстановить вручную.

## Известные ограничения
- Только консольный интерфейс.
- Изменять можно состояние и кабинет, остальные поля после создания не меняются.
- Нет разграничения доступа и истории изменений.
- Файл данных рассчитан на одного пользователя.
